# 大四專題海報：選風格、跟 AI 一起做、跟評審說

網址：https://ymkcheng.github.io/courses/tools/capstone-poster/

給大同資工大四專題生的引導頁。學生照五步走：看十款風格選一款、下載海報工具包、跟自己的 AI 一起把現有海報搬到選定的風格、交件前檢查、站在海報前跟評審說。每款版面都是全寬系統架構圖（用 ①②③ 標運作順序）、真實操作畫面，加上介紹影片、現場試玩、GitHub 三個必放 QR。ChatGPT、Gemini、Claude、Copilot 都能用。

- `index.html`：引導頁。十款範本、給 AI 的說明書、校徽都包在這一個檔裡，工具包 zip 在瀏覽器裡當場產生，不需要伺服器
- `files/給AI的說明書.md`：單檔版說明書（技能本體加所有附錄）
- `files/templates/`：十款中文範本，打開即可預覽（需連網載入字型）
- `files/tatung-csie-poster-port.zip`：技能完整版，給支援技能資料夾的 AI

這裡只放輸出。來源（產生範本與圖的程式、技能原始檔）在本機「大學部專題2025／原始檔」，在那裡改完再重新產生、推上來。
